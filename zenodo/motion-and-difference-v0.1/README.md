# Zenodo preparation - Motion and Difference

This folder contains the metadata and upload sequence for the archival Zenodo record of *Motion and Difference*.

The DOI is intentionally `PENDING`. Once Zenodo reserves or assigns it, run:

```bash
python scripts/apply_motion_difference_doi.py 10.5281/zenodo.XXXXXXX
```

The patch is constrained to the existing `CoppaMotionDifference2026` bibliography entry in CCLQG v1.1.
