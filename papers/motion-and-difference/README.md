# Motion and Difference

**Anthony Vito Coppa - 17 July 2026**

This directory preserves the canonical nine-page PDF of *Motion and Difference* as a public archival research artifact.

The paper constructs one bounded mathematical realization joining projective dynamics, Fibonacci structure, hyperbolic geometry, and a Lorentzian `SO(2)` gauge field while keeping the participating quantities separately typed. Its gauge section supplies the explicit result used by the covariant-LQG continuum-closure paper: exact compatibility of local descriptions can coexist with nonzero source-free curvature, nontrivial holonomy, and unequal proper time.

The archived PDF itself lists the author as **Independent Researcher**. That historical title-page provenance is retained unchanged. Repository placement under Coppalini Architecture does not rewrite the original document.
