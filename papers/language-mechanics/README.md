# Language Mechanics formal basis

This directory contains the complete numbered 000-011 sequence in stable PDF and LaTeX form.

The `ca-03-tool-and-technique` directory is the requested repository placement for the Coppalini Architecture extension *Tool & Technique*. Its retained v0.1 manuscript identifies itself internally as “Methodology Basis 01.” That discrepancy is recorded rather than silently rewritten; a later author-approved edition can reconcile the numbering in both source and PDF.

Field logs, early forms, archive copies, build intermediates, audit programs, and duplicate release bundles are intentionally excluded.
