## Purpose

This note supplies the compact supporting witness used by the continuum-closure program. It separates two questions:

1. do local descriptions glue exactly?;
2. is the physical connection flat/trivial?

The construction shows that the first can close while the second remains nontrivial.

## Result

A nonnegative gluing functional is built from local section, connection, and transition defects. Its zero locus is exact compatibility. On a Lorentzian product spacetime, an explicit `SO(2)` connection simultaneously supports:

- exact local gluing;
- nonzero source-free Maxwell curvature;
- independently tunable global holonomy;
- endpoint-sharing timelike paths with unequal proper time.

The conclusion is narrow: **compatibility closure is not a physical flatness condition**.
