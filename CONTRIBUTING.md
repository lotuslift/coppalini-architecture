# Contributing

This repository uses first-failure, source-authority, and receipt discipline.

A proposed change should state:

1. the source/reference it changes or extends;
2. the operation being performed;
3. the required relations that must survive;
4. any new bridge, strengthening warrant, or scope authority;
5. an executable witness or falsifier where appropriate;
6. the resulting status and remaining open edge.

Do not silently upgrade `OPEN` to `CERTIFIED`, a finite computation to a universal theorem, or an application example to a domain-wide empirical claim.

For research papers, preserve the native literature boundary and clearly distinguish imported results from new constructions.
